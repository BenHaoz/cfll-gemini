# 知网导出文件（补入文献中心未收录的期刊）

国家哲学社会科学文献中心没有收录《广西民族研究》《中南民族大学学报（人文社会科学版）》《民族学刊》《中华民族共同体研究》等核心期刊，这些刊的文章靠本目录下的知网导出文件补入文章库。

## 导出步骤

1. 在知网高级检索中设定条件，例如"文献来源 = 广西民族研究，发表时间 = 2024-01-01 至今"，或"作者 = 郝国强，作者单位 = 广西民族大学"。
2. 结果页"全选"（每页最多 50 条，需逐页全选，一次最多导出 500 条），点击"导出与分析 → 导出文献"。
3. 选 **RefWorks** 或 **EndNote** 格式（含作者单位，最稳妥）后点"导出"；也可以选"自定义"，勾选题名、作者、单位、文献来源、年、期、发表时间，导出为 Excel。
4. 把文件放进本目录（文件名随意，如 `广西民族研究-2024-2026.txt`），提交到仓库。

## 导入

每周一的采集工作流会自动执行导入；也可以手动运行：

```bash
python -m ethno_monitor import-cnki                  # 导入本目录下全部文件
python -m ethno_monitor import-cnki 某文件.txt        # 只导入指定文件
python -m ethno_monitor authors --institution 广西民族大学   # 查看某单位作者发文排名
```

- 导入可以重复运行：同刊同题的文章会合并，不会重复计数。文献中心已有的文章，只补全缺失的作者单位。
- 只收 `config/journals_core.yaml` 中等级为 CSSCI 来源、CSSCI 扩展或北大核心的期刊，与周报排名口径一致；其余期刊（如《湖北大学学报》这类综合类学报）会在输出的 `skipped` 中列出，不计入统计。
- 旧版二进制 .xls 文件无法直接读取，需另存为 .xlsx，或改用 RefWorks / EndNote 格式导出。
